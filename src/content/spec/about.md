# 关于我

你好，我是 **或记**。

一个普通的内容记录者。大部分时间在生活里，少部分时间在文字里。

## 这里是什么

这个博客没有垂直定位，也不打算有。它会放一些读过的书、走过的路、想明白或者没想明白的事。

如果一定要说主题，大概是：**认真地生活，诚实地记录。**

## 关于名字

「或」是不确定，「记」是记录。合在一起，是「或许值得记下来」。

很多事情我并没有想得那么清楚，写下来的东西也只是某个时刻的真实想法。它们不保证正确，只保证当时真诚。

## 关于本站

本站使用 [Astro](https://astro.build/) 构建，主题基于 [Firefly](https://github.com/CuteLeaf/Firefly)。

首页的壁纸、头像与文章封面通过 Safebooru API 按横竖尺寸筛选，并保留作品页与原始出处；版权归原作者所有，仅作个人博客装饰。完整来源见[图片来源](/credits/)。
